## Differential rounding gestures converge acoustically: Evidence from Mandarin sibilants and high front vowels.

Baichen Du (Department of Linguistics, University of California-Los Angeles, CA, USA)

Alexandra Pfiffner (Department of Linguistics, University of Georgia, Athens, GA, USA)

Due to recent changes to osf.io, no new project can be added post early 2027. We therefore use this Github repository to host supplementary files for this paper.

This repository consists of 1. the analysis script in .Rmd, 2. the compiled HTML file, 3. figures that are generated by the Rmd and presented in the manuscript.
